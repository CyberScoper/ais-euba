# Index

Неофіційний клієнт **AIS2 Економічного університету в Братиславі** (`ais2.euba.sk`): розклад,
предмети та оцінки, платежі й повідомлення на одному екрані, що відкривається в телефоні менш ніж за
секунду. Це PWA з невеликим Node-сервером за нею, і вона розрахована на власний хостинг — один
примірник на людину або на коло людей, які довіряють одне одному.

</p>

## Що вміє

- **Сьогодні** — пара, яка триває просто зараз, або найближча, скільки ви винні та що лежить у
  вхідних. До початку семестру екран каже, коли він почнеться, замість того щоб бути порожнім.
- **Розклад** — на комп'ютері тиждень сіткою, у телефоні по днях. Лекції та семінари мають свої
  кольори; вільний день показує найближчий день, який не вільний.
- **Предмети** — записані предмети, кредити, оцінки та середньозважений бал, плюс план навчання.
- **Фінанси та повідомлення** — платежі разом зі змінним символом, а поруч стрічка повідомлень з
  AIS: більшість із них однаково про платежі.
- **Університет** — практичні речі, яких в AIS немає: транспорт від гуртожитків, їдальні,
  бібліотека, продовження ISIC, університетська пошта.
- **Чотири мови** — словацька, російська, українська та англійська, у кожної свої правила множини й
  форми дат. Те, що надсилає сам AIS (назви предметів, категорії повідомлень), лишається словацьким,
  і застосунок прямо про це каже.
- **Встановлюється як застосунок** — це справжня PWA: вона сама пропонує встановлення, оболонка
  працює офлайн, а дані — ні, бо оцінка з кешу це неправильна оцінка.

## Як це влаштовано

AIS не має публічного API, а його політика CORS унеможливлює звернення з браузера. Тому тут
**проксі на сервері** — не розширення для браузера й не інструмент на кшталт «вставте сюди свою
cookie»:

<p align="center">
  <img src="docs/readme/flow.svg" alt="PWA говорить із цим Node-сервером, який тримає сесію AIS і читає ais2.euba.sk" width="100%">
</p>

Ланцюг авторизації той самий, що й в офіційної Angular-SPA: POST на `/ais/login.do` по `JSESSIONID`,
токен із `/ais/rest/apps/get-access-token`, і далі кожен REST-виклик несе і те, і те. Сервер оновлює
токен, коли той старіє, і входить наново не частіше ніж раз на хвилину.

Пароль від AIS потрібен для входу й після цього живе **в пам'яті сервера**. Якщо поставити позначку
«залишатися в системі», він додатково зберігається зашифрованим (AES-256-GCM) у каталозі стану, а
ключ лежить поруч у файлі з правами `0600`. Це захищає від викраденої резервної копії, а не від
того, хто вже дістався машини, — і екран входу каже про це саме такими словами, перш ніж ви почнете
писати.

### Ввічливий клієнт

Усе, що йде вгору, проходить через один регулятор: мінімальний проміжок між викликами, стеля на
хвилину, джитер, склеювання однакових одночасних читань в один запит і кеш із власним строком життя
для кожного ендпоїнта (розклад живе п'ятнадцять хвилин). Повторювані невдалі входи зупиняє
запобіжник, заведений **окремо на кожен акаунт**: саме гупання хибним паролем і блокує акаунт в AIS.

## Запуск

```bash
npm install
AIS_MOCK=1 npm start     # демодані, акаунт AIS не потрібен — http://localhost:4173
npm start                # бойовий режим, вхід даними від AIS2
```

На сервері все робить `deploy/deploy.sh` — systemd-юніт, nginx-vhost, Let's Encrypt:

```bash
DOMAIN=ais.example.com LE_EMAIL=you@example.com deploy/deploy.sh
```

Застосунок слухає лише localhost; TLS завершуйте перед ним.

| Змінна | Типово | Що це |
| --- | --- | --- |
| `PORT` | `4173` | порт, який слухати |
| `AIS_BASE` | `https://ais2.euba.sk` | адреса AIS |
| `AIS_LNG` | `SK` | мова, якою відповідає AIS |
| `AIS_SECRET` | — | ключ для шифрування запам'ятаних паролів (64 hex-символи або парольна фраза); інакше ключ згенерується у файл |
| `AIS_STATE_DIR` | `/var/lib/ais-pwa` | де лежать сесії та цей ключ |
| `AIS_SESSION_DAYS` | `30` | скільки живе запам'ятана сесія |
| `AIS_GA_ID` | — | ідентифікатор аналітики для цього примірника, якщо вона взагалі потрібна |
| `AIS_MOCK` | — | `1` — демодані, AIS не чіпається зовсім |
| `AIS_RAW` | — | `1` вмикає read-only passthrough для калібрування адаптерів; у бою тримайте вимкненим |

## Що де лежить

```
server/aisClient.js     ланцюг авторизації AIS, REST і нормалізація відповідей
server/security.js      заголовки, ліміти, перевірка джерела, безпека шляхів
server/guard.js         регулятор, склеювання викликів, кеш, запобіжник на вхід
server/sessionStore.js  сесії на диску та запечатаний пароль за «залишатися в системі»
server/index.js         express: сесії, чистий /api/*, віддача статики
public/                 сама PWA — без збірки, без фреймворку, без бандлера
public/i18n.js          кожна фраза чотирма мовами, зі своїми правилами чисел
scripts/handbook/       джерела екрана «Університет»; public/handbook.js генерується
```

## Безпека

- cookie сесії — `HttpOnly`, `SameSite=Lax`, `Secure`, 192 біти ентропії, ковзний строк життя;
  запити з чужого джерела, що змінюють стан, відхиляються одразу;
- сувора Content-Security-Policy з `frame-ancestors 'none'` і без жодного інлайн-скрипта;
- `Cache-Control: no-store` на кожній відповіді API;
- ліміти за IP перед API і суворіший перед формою входу;
- passthrough дозволяє шляхи в AIS **поіменно** й відхиляє все, де є `..`: в AIS деструктивні
  операції доступні звичайним `GET`, тож забороняти за методом було б недостатньо;
- перехоплені реальні відповіді AIS (для офлайн-QA) лежать у `.gitignore` і ніколи не потрапляли в
  коміти.

Знайшли дірку? Див. [SECURITY.md](SECURITY.md).

## Чим це не є

Це **не проєкт університету, він його не схвалював і ніяк із ним не пов'язаний**. Клієнт читає ті
самі дані, що й офіційний клієнт AIS2, вашими ж обліковими даними, на сервері, який контролюєте ви, і
ніколи нічого не записує в AIS: будь-який виклик — читання.

Екран «Університет» — це знімок публічних сторінок Студентського парламенту, переказаний власними
словами, з посиланням на джерело та датою останньої звірки на кожній картці. Це не дзеркало тексту
університету, і якщо дані розійдуться, мають рацію сторінки університету.

Якщо сервер тримаєте не ви, ви довіряєте свій університетський пароль тому, хто його тримає. Це
реальна ціна, і чесна порада — підняти власний примірник.
